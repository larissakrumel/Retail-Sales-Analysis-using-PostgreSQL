# Retail Sales Analysis using PostgreSQL

This project analyses a small retail sales database using PostgreSQL and SQL.

The database includes customer, order, product, and sales data.

## Objectives

The analysis focuses on answering simple business questions such as:

- Which customers made repeat purchases?
- How much did each customer spend?
- When did each customer make their first purchase?
- Which product categories generated the most revenue?

## Tools

- PostgreSQL
- DBeaver
- SQL
